## Detekce phishingových URL pomocí jazykových modelů

Cílem práce je navrhnout a implementovat systém pro detekci phishingových adres v e-mailech pomocí metod strojového učení, zejména jazykových modelů. Student sestaví datovou sadu vytvořenou z veřejně dostupných dat, natrénuje na ní několik modelů a porovná je, se zaměřením na vztahy mezi velikostí modelu, rychlostí inference a přesností výsledku. Výsledný kód by měl být řádně zdokumentován a při jeho vývoji by měl být využit verzovací systém (např. git). 

* Nastudujte metody analýzy spamu a podvodných e-mailů.
* Sestavte trénovací dataset pro e-maily s phishingovými adresami.
* Natrénujte na datasetu několik různých typů modelů a porovnejte je.
* Navrhněte, jak by mohly tyto metody analýzy být integrovány do existujících e-mailových klientů
